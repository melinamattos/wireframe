# Sistema de Controle de Estoque

Projeto desenvolvido para auxiliar no controle de estoque de materiais.

## Sobre o projeto

O sistema tem como objetivo facilitar o registro e acompanhamento dos materiais, permitindo controlar entradas, saídas e quantidade disponível em estoque.

## Protótipo

O protótipo das telas foi desenvolvido no Figma.

**Link do Figma:** https://www.figma.com/design/qa1ILxtdJiewd2oalccOln/Wireframe-Media-Fidelidade?node-id=1-2&p=f

## Tecnologias

* Figma

## Objetivo

Facilitar o controle dos materiais e reduzir erros no registro de entradas e saídas de estoque.
